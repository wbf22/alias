


# Folding

| command | effect      |
|----|-----|
|   za    | toggle fold |
|   zr    | reduce folding one level |
|   zm    | increase folding one level |


`:set foldmethod=syntax` to set folding


# Moving between files

| command | effect      |
|----|-----|
| :Explore` | to switch to a file explorer and navigate to another file |
| :grep -rn "<search term>" .` | search the repo `:cn` and `:cp` for next and previous result, ` |
